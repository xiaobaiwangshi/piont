# 混合学习资料库设计

## 目标

在不修改 `raw/`、`raw_doc/` 和现有原始文档的前提下，建立一套可离线阅读、可追溯版本、从基础延伸到源码与实战的计算机及 Web 服务端学习资料库。

## 范围

资料覆盖以下主线：

1. 计算机组成原理、操作系统、计算机网络、数据结构与算法。
2. 设计原则与设计模式。
3. Web 标准、PHP、Node.js、Nginx、Linux 与 LNMP。
4. MySQL、Redis、Elasticsearch、MongoDB、Kafka、RabbitMQ、Memcached、RPC。
5. 分布式系统、系统设计、容器、可观测性和 Web 安全。

`applet.zip`、无法确认授权的商业电子书、仓库历史记录和构建产物不在范围内。

## 资料分层

每个主题按下列层次选材，不使用源码仓库代替教材：

1. **开放教材或大学课程**：负责完整知识路径、概念解释和练习。
2. **官方版本文档**：负责 API、配置、行为和版本差异。
3. **实验与示例**：负责可运行案例、故障实验和验证步骤。
4. **源码与实现资料**：只用于高阶机制分析。
5. **中文整理文档**：连接前四层，提供学习顺序、版本矩阵、问题索引和验收标准。

## 目录设计

```text
learning-materials/
├── README.md                 # 总入口和使用说明
├── manifest.tsv              # 资料名、来源、版本、提交、许可证和本地路径
├── 01-计算机基础/
├── 02-Web与服务端/
├── 03-数据库与中间件/
├── 04-分布式与架构/
├── 05-运维可观测性与安全/
└── 99-外部链接/              # 不能合法镜像的资料只保存链接和说明

knowledge-base/
├── 08-资料导读/              # 新生成的中文学习导航
└── 99-勘误与来源.md          # 增加新资料索引，不改原始档案
```

每个下载项目使用独立目录，并保存 `SOURCE.md`，记录来源 URL、固定版本或提交、下载日期、许可证、用途及适用知识章节。

## 版本策略

- MySQL：5.7 作为遗留生产版本，8.0 为主体，8.4 LTS 为补充。
- PHP：7.4 作为遗留项目参考，8.2 至 8.4 为现代实践。
- Linux：原理不绑定版本；实现示例优先选择 5.10、6.1、6.6 等长期维护系列。
- TCP/IP：按 RFC 和机制组织，不虚构软件版本；同时说明 Linux 实现。
- Redis：覆盖 6.2、7.x，并记录 8.x 变化。
- Elasticsearch：覆盖 7.17、8.x，新主版本只作差异补充。
- Kafka、RabbitMQ、Node.js、Nginx：选择仍常见的生产版本与较新稳定版本对照。

版本资料优先固定 release、tag 或明确分支；不直接把 `main`、`master`、`trunk`、`unstable` 当成稳定教材版本。

## 下载策略

- 文档型仓库使用浅克隆或发布快照，保留完整文档与示例。
- 课程和实验仓库保留实验代码、讲义和测试，不下载 Git 历史。
- 大型产品源码仅在确有源码学习价值时下载；普通使用学习只保存官方文档。
- 官方文档不在 GitHub 时，使用官方可下载版本；禁止绕过登录、付费或版权限制。
- 所有来源先核对许可证。无法确认再分发权限的资料只写入外部链接索引。

## 中文整理产物

新文档按以下统一结构组织：

1. 学习目标和前置知识。
2. 基础概念与核心原理。
3. 深入机制与版本差异。
4. 使用案例和最小实验。
5. 解决的问题、适用边界和常见误区。
6. 推荐阅读顺序和对应本地资料。
7. 可执行验收清单。

中文整理只归纳、纠错和建立导航，不大段复制受版权保护内容。

## 失败处理

- 下载失败保留在清单中并记录原因，不用非官方镜像静默替代。
- 仓库不存在、已归档或许可证不明确时，标记为待替换。
- 版本分支消失时优先固定官方 tag；找不到稳定版本则只保留官方在线文档链接。
- 单个大型仓库失败不阻塞其他主题，最终验收明确列出缺项。

## 验收标准

1. `raw/`、`raw_doc/` 内容和时间戳不因本任务改变。
2. 每份本地资料都能从 `manifest.tsv` 追溯到来源和固定版本。
3. 每个主知识领域至少有一份系统教材或课程、一份权威文档和一组案例/实验；确实不存在时明确标注。
4. MySQL 5.7、8.0、8.4 的资料入口相互独立，避免混用行为。
5. 所有新 Markdown 内部链接通过检查，不存在空文件和明显下载错误页。
6. 生成的中文导读能够从基础课连接到 Web、组件、架构和故障排查。
