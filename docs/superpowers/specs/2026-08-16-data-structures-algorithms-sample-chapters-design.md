# 数据结构与算法样板章节精修设计

## 目标

把“数据结构与算法”精修为四大基础课程的最后一个样板教程。读者应能从问题约束选择结构与算法，写清时间/空间复杂度和前提，解释正确性，并把基础结构映射到 MySQL、Redis、Kafka、任务调度和大数据处理。

## 方案选择

采用“两文件原位精修”：

- `knowledge-base/01-基础/04-数据结构与算法.md`：负责完整学习顺序、复杂度、基础结构、算法思想、定量计算、案例、误区和自测。
- `knowledge-base/07-核心机制深入/03-数据结构与算法工程.md`：负责不变量、摊还分析、概率结构、外部算法、并发结构和工程验证思路。

未采用的方案：按每种结构拆文件会增加导航成本；新增代码仓库会偏离个人知识库目标；全部内容放入主章会重复现有工程深入章节。

## 范围与约束

- 不修改 `raw_doc_`、`raw/` 和已下载资料。
- 不新增或运行算法程序、benchmark、测试框架与实验工程。
- 伪代码、公式、表格和输入样例仅用于解释知识。
- 固定容量和性能数字必须注明数据规模、分布、内存模型或估算假设。
- 复杂度必须区分最好、平均、最坏、期望或摊还口径。
- 保留现有正确内容，纠正常见口诀和产品实现误解。

## 主章节结构

按“问题约束 → 成本模型 → 数据结构 → 算法 → 真实系统”组织：

1. 学习目标、先修知识和主章/深入章阅读边界。
2. 渐进复杂度、时间/空间权衡、最好/平均/最坏、摊还分析和输入分布。
3. 数组、链表、栈、队列、双端队列及缓存局部性。
4. 哈希表：哈希、冲突、装载因子、扩容和退化边界。
5. 树与堆：BST、AVL/红黑树概念、堆、B/B+ 树、Trie 和区间结构的选择。
6. 图与并查集：表示方式、BFS/DFS、拓扑排序、最短路、最小生成树和连通性。
7. 查找、排序与选择：二分、插入、归并、快排、堆排、线性排序、Top K。
8. 分治、贪心、动态规划、回溯及正确性证明思路。
9. 定量算例：复杂度增长、动态数组摊还、堆 Top K、图存储、Bloom Filter 和外部归并。
10. MySQL B+ 树、Redis dict/skiplist、Kafka 日志、LRU、依赖调度等案例。
11. 问题证据链、常见误区、稳定原理/产品版本边界、十道自测题与答案。

## 工程深入章节职责

深入章节不重复结构定义，集中解释：

- 操作前后必须保持的不变量以及循环不变量。
- 动态数组和哈希扩容为什么是摊还常数级。
- AVL、红黑树、B+ 树、Trie、Segment Tree、Fenwick Tree 的约束差异。
- Bloom Filter、Count-Min Sketch、HyperLogLog、Reservoir Sampling 的误差边界。
- 粗粒度锁、分片、copy-on-write、CAS 与无锁内存回收的代价。
- 外部排序、页访问模型、内存受限 Top K 与失败恢复。
- 用边界集、性质、反例和复杂度模型验证结论，但本轮不实际执行测试或 benchmark。

## 计算与推导

- 复杂度增长：比较 `n`、`n log n`、`n²` 在给定规模下的操作数量级。
- 动态数组：容量倍增时把搬迁成本分摊到多次追加。
- 哈希表：由元素数与装载因子估算桶容量，说明最坏退化。
- Top K：比较完整排序 `O(n log n)` 与大小 K 的堆 `O(n log k)`。
- 图：邻接矩阵 `O(V²)` 与邻接表 `O(V+E)` 空间边界。
- Bloom Filter：使用 `m ≈ -n ln p / (ln 2)²` 和 `k ≈ (m/n) ln 2` 估算位数与哈希次数。
- 外部归并：根据内存、数据量和归并路数估算初始段、趟数与临时空间。

所有答案必须说明变量、前提和数量级意义，不把理论比较次数直接等同于墙上时间。

## 正确性与案例设计

- 查找/遍历通过循环不变量或已访问集合解释为什么不会漏解。
- 贪心必须说明交换论证、切分性质或给出反例，不能因“每步看起来最好”就宣称最优。
- 动态规划必须说明状态定义、转移来源、初始化与遍历依赖。
- 图算法先确认有向性、权值范围、负边、稠密度、连通性和是否需要路径本身。
- 案例强调“解决的问题与代价”，不把教科书结构等同于某产品当前源码。

## 来源与纠错

- 基础结构参考 `raw_doc_` 的软件设计资料、Open Data Structures 和开放算法教材。
- B+ 树、Redis、Kafka 等产品映射以知识库对应章节及其版本文档校正。
- 老资料中的固定阈值、容器源码和产品内部编码必须标注版本，不能上升为算法定义。
- 不复制教材大段原文，只重新组织稳定知识、公式和反例。

## 验收

- 两文件职责清晰，结构定义与工程推导不成段重复。
- 主章节覆盖线性结构、哈希、树/堆、图、排序/选择和主要算法思想。
- 至少包含复杂度、摊还、Top K、图存储、Bloom Filter、外部排序六类计算。
- 案例连接 MySQL、Redis、Kafka、缓存和任务依赖。
- 主章节包含故障/选择证据链、十条常见误区、十道自测题与参考答案。
- 深入章节把原 benchmark/验证内容改为非执行的评估思路。
- Markdown 本地链接有效、代码围栏配对、无尾随空格和占位内容。
