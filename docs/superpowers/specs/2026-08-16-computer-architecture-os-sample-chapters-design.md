# 计算机组成原理与操作系统样板章节精修设计

## 目标

把“计算机组成原理”和“操作系统”精修为继网络、MySQL 之后的两个样板教程。读者应能从程序、指令、CPU、内存、内核、文件与设备建立完整因果链，完成常用定量估算，并解释服务端常见性能与资源问题。

## 方案选择

采用“三文件原位精修”：

- `knowledge-base/01-基础/01-计算机组成原理.md`：负责组成原理的学习顺序、公式、案例、排查、误区和自测。
- `knowledge-base/01-基础/03-操作系统.md`：负责操作系统的学习顺序、资源模型、案例、排查、误区和自测。
- `knowledge-base/07-核心机制深入/01-硬件与操作系统.md`：负责流水线、Cache、页表、调度和 I/O 路径等内部机制，只引用主章节已定义的公式。

未采用的方案：新增两个深入文件会拆散现有硬件—内核因果链；全部塞进两个主章节会重复深入内容；创建实验工程超出本轮“只整理知识”的范围。

## 范围与约束

- 不修改 `raw_doc_`、`raw/` 和已下载学习资料。
- 不新增程序、容器、虚拟机、内核编译或性能实验。
- 命令、伪代码和计算题仅作知识示例，本轮不执行实验。
- 固定数字必须注明架构、Linux 版本、配置或估算假设。
- 稳定原理与具体实现分开表述，不把 x86、RISC-V 或某个 Linux 内核版本当成唯一实现。
- 保留现有知识，只纠错、补缺口和减少重复。

## 计算机组成原理主章节

按“数据如何成为指令并在硬件中执行”组织：

1. 学习目标、先修知识、ISA 与微架构边界。
2. 二进制、补码、溢出、IEEE 754、字节序和编码。
3. CPU、寄存器、ALU、控制器、总线、存储器和 I/O 设备。
4. 取指、译码、执行、访存、写回，以及异常和中断。
5. CPU 时间公式、CPI/IPC、主频、加速比和 Amdahl 定律。
6. 流水线风险、超标量、乱序执行、分支预测和顺序提交。
7. 存储层次、Cache line、直接映射/组相联、地址拆分、命中率和 AMAT。
8. 缓存一致性、内存可见性与 false sharing 的边界。
9. DRAM、SSD/HDD、总线、DMA、中断和零拷贝。
10. 服务容量、缓存地址、AMAT、Amdahl 和传输时间算例。
11. CPU/内存/I/O 问题的证据链、常见误区、版本边界、十道自测题与答案。

## 操作系统主章节

按“应用如何通过内核获得隔离和共享资源”组织：

1. 学习目标、用户态/内核态、系统调用和异常/中断边界。
2. 程序、进程、线程、协程，进程状态、创建、退出、僵尸与孤儿进程。
3. 调度目标、运行队列、抢占、优先级、CPU 密集/I/O 密集与上下文切换。
4. 互斥锁、读写锁、信号量、条件变量、原子操作、竞态和死锁。
5. 虚拟地址、页表、TLB、缺页、COW、`mmap`、匿名页、页缓存、swap、回收和 OOM。
6. 页数量、页表占用、地址拆分与内存容量估算。
7. VFS、inode、dentry、文件对象、文件描述符、page cache、writeback、`fsync` 和 journaling 边界。
8. 阻塞/非阻塞、同步/异步、select/poll/epoll 与 `io_uring` 的语义边界。
9. 设备驱动、中断、DMA，以及 namespace、cgroup 和容器资源视图。
10. CPU、内存、fd、磁盘和不可中断 I/O 的证据链、常见误区、Linux 版本边界、十道自测题与答案。

## 深入章节职责

深入章节沿一条内部执行链组织：指令与流水线 → Cache 与一致性 → 地址翻译与 NUMA → 调度和同步 → 系统调用、VFS、页缓存与块设备 → DMA/中断 → namespace/cgroup。主章节负责首次定义概念和计算公式，深入章节负责解释状态变化、硬件与内核的交界以及指标为何出现。

原“实验与验证”改为“观察思路与命令示例”，明确命令不要求执行。网络协议栈细节继续留在网络深入章节，不在本章重复。

## 计算题与案例

- 组成原理：`CPU time = instruction_count × CPI / clock_rate`、IPC/CPI 换算、Amdahl 加速上限、Cache tag/index/offset、AMAT、带宽传输时间和 CPU 容量。
- 操作系统：虚拟页数量、多级页表数量级、可用 fd 上限、COW 内存放大、CPU 核数与可运行任务、写入完成层次。
- 情景题只整理证据链，例如“CPU 使用率不高但 load average 高”“free 很少是否等于内存不足”“write 成功后断电为何仍可能丢数据”。

所有算例必须写明位宽、页大小、Cache 配置、核心数或工作负载等假设；答案给出推导和适用边界。

## 来源与纠错

- 稳定原理以 `raw_doc_/计算机组成原理.pdf`、体系结构开放教材和 RISC-V ISA 文档交叉核对。
- 操作系统原理以本地 Linux 资料、OSTEP、xv6 教材和 Linux 官方文档交叉核对。
- 老资料中的命令和调度器实现只保留历史价值；现代 Linux 行为必须标注发行版、内核或“实现会演进”。
- 不复制书籍大段原文，只提取稳定概念并重新组织。

## 验收

- 三个文件职责清晰，公式和内部机制不成段重复。
- 组成原理覆盖数据表示、指令、流水线、Cache、存储与 I/O，并含至少五类定量计算。
- 操作系统覆盖进程调度、同步、虚拟内存、文件系统、I/O 和容器基础，并含资源估算。
- 两个主章节均有学习目标、案例、故障证据链、常见误区、版本边界、十道自测题与参考答案。
- 深入章节不要求执行实验，不扩写网络协议栈。
- Markdown 本地链接有效、代码围栏配对、无尾随空格和占位内容。
