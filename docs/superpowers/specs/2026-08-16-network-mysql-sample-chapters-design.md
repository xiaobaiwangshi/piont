# 网络与 MySQL 样板章节精修设计

## 目标

把“计算机网络”和“MySQL”精修为知识库中的两章样板教程。读者应能从基本概念建立完整因果链，理解内部机制和定量关系，读懂使用案例，判断常见故障，并通过自测题检查理解程度。

## 方案选择

采用“两层原位精修”：保留现有主章节和深入章节，不新建主题目录。

- 主章节：完整学习顺序、基础概念、公式、案例、排障、版本边界、自测题与答案。
- 深入章节：只放需要内核/存储视角、更多推导或跨组件比较的内容，并链接回主章节。

未采用的方案：把每个主题拆成多个小文件会增加导航成本；把全部内容塞入单一主文件会与现有深入章节重复；另建补充文档会形成多个入口。

- 只修改以下四个现有文件：
  - `knowledge-base/01-基础/02-计算机网络.md`

- 可以提供命令、SQL、计算例题和故障场景作为知识示例，但本阶段不执行实际实验。

- 固定数字必须注明协议、产品版本、配置或估算假设。
- 不复制书籍大段原文；使用重新组织的中文说明，并给出来源线索。

## 网络主章节结构

按数据从本机到远端应用的路径组织：

1. 学习目标与先修知识。
2. 分层、封装、链路、Ethernet、ARP/NDP、VLAN、MTU/MSS。
3. IPv4/IPv6、CIDR、最长前缀匹配、ICMP、路由与 NAT。
4. UDP 与 TCP：连接、序列号、累计 ACK、SACK、重传、滑动窗口、零窗口。
5. TCP 拥塞控制：慢启动、拥塞避免、快速恢复、RTO、RTT、CUBIC/BBR 边界。
6. BDP、窗口吞吐、分片、队列和连接容量算例。
7. DNS、TLS、HTTP/1.1、HTTP/2、HTTP/3、SSE 与 WebSocket。
8. 一次 HTTPS 请求的完整链路。
9. 常见问题：DNS 错误、连接拒绝/超时、重传、吞吐低、502/504、PMTU 黑洞。
10. 版本边界、易错结论、自测题与参考答案。

## 网络深入章节职责

只补充主章节不宜展开的内容：主机发包/收包路径、网卡 DMA/中断与软中断、socket 缓冲、listen/accept 队列、NAT/conntrack、TIME_WAIT、offload、TCP 状态与性能证据链、TLS 1.3 和 HTTP 多路复用边界。公式在主章节首次定义，深入章节引用而不重复推导。

## MySQL 主章节结构

按 SQL 从进入服务到数据持久化和复制的路径组织：

1. 学习目标、关系模型和 Server/存储引擎边界。
2. 连接、解析、优化、执行与结果返回。
3. InnoDB 表空间、段、区、页、行格式和溢出页。
4. Buffer Pool：页框、free/LRU/flush、命中率、脏页与工作集。
5. B+ 树：聚簇/二级索引、页结构、扇出、树高、覆盖索引和回表。
6. 索引设计：联合索引、最左前缀、选择性、排序、ICP、MRR 与成本模型边界。
7. 优化器与执行计划：基数估算、访问路径、join、排序、临时表和 `EXPLAIN ANALYZE`。
8. 事务：ACID、MVCC、Read View、undo、锁、next-key lock、死锁和隔离级别。
9. 持久化：redo、binlog、两阶段提交、checkpoint、doublewrite 与崩溃恢复。
10. 复制、备份、恢复、GTID 和延迟问题模型。
11. MySQL 5.7、8.0、8.4 的差异、常见故障、自测题与参考答案。

## MySQL 深入章节职责

在“数据系统内部机制”中只加强 MySQL 相关段落：页生命周期、WAL/checkpoint/doublewrite、Buffer Pool 工作集、MVCC 版本链、日志协调、二级索引访问成本和复制恢复边界。Redis、Elasticsearch、Kafka 段落不在本阶段扩展。

## 案例与自测设计

每章都包含三类内容，但不执行实验：

- 计算题：网络 BDP/窗口吞吐/积压，MySQL 页容量/扇出/树高/Buffer Pool 页框。
- 情景题：从现象选择证据链，例如“带宽高但单连接慢”“索引存在但扫描仍多”。
- 易错题：解释为什么常见口诀不成立，例如“滑动窗口等于拥塞窗口”“B+ 树固定三层”“`!=` 必然索引失效”。

参考答案紧随章节末尾，回答必须包含假设、推导、边界和验证思路，不能只给结论。
