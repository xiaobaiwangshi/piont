# 个人计算机与 Web 服务端知识库

本目录是从 `raw/`、`raw_doc_` 等原始资料重新整理，并由开放教材、RFC 和官方文档校正补充的知识体系。原始资料保持不变；这里负责归类、去重、纠错、版本标注和实验验收。

## 知识主线

```text
计算机组成原理
  ├─ CPU、内存、磁盘、总线
  └─ 性能上限与成本模型
         ↓
操作系统 ──────── 数据结构与算法
  ├─ 进程/线程       ├─ 数据组织
  ├─ 内存/文件       └─ 复杂度与解题方法
  └─ I/O 与网络栈
         ↓
计算机网络 → Web 请求全链路 → PHP/Go 应用 → LNMP
                                   ↓
                 MySQL / Redis / Elasticsearch / Kafka
                                   ↓
                 高并发、高可用、安全、可观测性
                                   ↓
                       案例实践与故障排查
                                   ↓
            大模型基础 → RAG/工具/MCP → Agent 生产工程
```

## 每篇文档的组织规则

1. 基础知识：先回答“是什么”和“为什么”。
2. 高阶知识：解释内部机制、边界和取舍。
3. 使用案例：给出可落地的命令、配置或代码思路。
4. 解决问题：按“现象 → 证据 → 定位 → 处理 → 验证”组织。
5. 版本相关内容必须注明版本；容量数字必须经过实测，不能当作固定结论。

## 使用原则

- `raw/` 是原始档案，不直接修改。
- `raw_doc_` 中的 PDF/CHM/ZIP 同样只读；扫描资料只在临时目录定向转换和 OCR。
- `learning-materials/` 是核对来源，`knowledge-base/` 才是日常学习入口。
- 本目录中的命令用于理解和模板参考，生产执行前必须核对系统版本、路径和权限。
- 安全、事务、金额和数据删除场景不能省略校验、回滚与审计。
- AI 对话只作为线索；与官方文档、实际行为冲突时，以可复现验证和官方资料为准。
