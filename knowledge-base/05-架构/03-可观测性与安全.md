# 可观测性与安全

## 可观测性基础

可观测性用于通过系统输出推断内部状态，核心包括：

- Metrics：聚合趋势和告警。
- Logs：离散事件与上下文。
- Traces：一次请求跨服务的因果链。
- Profiles：CPU、内存、锁等代码级成本。

### 指标设计

服务优先观察 RED：

- Rate：请求速率。
- Errors：错误率。
- Duration：延迟分布。

资源优先观察 USE：

- Utilization：利用率。
- Saturation：排队/饱和。
- Errors：资源错误。

指标标签不能放用户 ID、完整 URL 等高基数值，否则 Prometheus 时序会爆炸。

### 日志

结构化记录时间、级别、service、request_id/trace_id、错误类型和必要业务标识。不要记录密码、Token、私钥、完整身份证或支付信息。

Nginx 同时记录 `$request_time` 和 `$upstream_response_time`，可区分客户端传输、代理开销和上游耗时。日志格式变更后，分析脚本必须同步版本。

### 告警

告警应表示需要行动的用户影响或即将耗尽的容量，不为每个短暂尖峰报警。每条告警需要负责人、阈值依据、Runbook 和静默/升级策略。

## 安全基础

### 认证与授权

- 认证：确认“是谁”。
- 授权：确认“能做什么”。
- 会话/Token 必须有过期、撤销和安全存储策略。
- 服务间使用独立身份与最小权限，不共享管理员密钥。

### 常见 Web 风险

- SQL 注入：参数化查询，禁止字符串拼 SQL。
- XSS：按输出上下文编码，配合 CSP；HttpOnly 只能降低 Cookie 被脚本读取风险，不能修复 XSS。
- CSRF：SameSite Cookie、CSRF Token、来源校验；验证码不是通用 CSRF 防护。
- SSRF：限制目标协议/域名/IP，防 DNS rebinding，隔离云元数据地址。
- 文件上传：限制大小、类型、扩展名，随机存储名，隔离执行权限，必要时扫描。
- 命令注入：不拼接 shell；使用参数数组和严格白名单。

### 密钥管理

密钥不进入代码库、日志或前端包。使用 KMS/Secret Manager，实施最小权限、轮换、审计和短期凭证。

Web 前端无法永久保守用于解密内容的私钥：合法客户端能解密，受控用户就可能提取明文或录屏。DRM 的目标是提高盗取成本、绑定硬件安全能力和许可证策略，不是数学上保证内容永不泄露。

## 高阶知识

### SLI、SLO 与错误预算

- SLI：实际测量指标，如成功请求比例。
- SLO：目标，如 30 天内 99.9% 成功。
- SLA：对外承诺及后果。
- 错误预算：允许失败量，用于平衡发布速度与可靠性。

### 监控 MySQL/Redis/Nginx/PHP-FPM

- Nginx：请求率、状态码、连接、request/upstream time。
- FPM：active/idle、max active、listen queue、slow requests。
- MySQL：连接、QPS、慢查询、Buffer Pool、锁、复制延迟、磁盘。
- Redis：内存、命中率、eviction、命令延迟、复制、fork、连接。

Exporter 使用专用只读账户和最小权限；监控端点不可直接暴露公网。

### 阿里云 Squid 监控

分三层：

1. 主机：CPU、内存、磁盘、网络。
2. 进程/端口：systemd 状态、进程数、监听端口。
3. 业务探测：通过 Squid 发起真实代理请求，验证能访问目标并记录延迟。

仅统计 `/usr/sbin/squid` 进程数可能因 master/worker 数变化误报；“进程存在”也不代表代理可用。应以业务探测为最终可用性信号。

## 使用案例

### 一次故障的证据链

```text
告警：5xx 上升
→ 指标：集中为 504，p99 增长
→ Trace：等待 MySQL
→ MySQL：锁等待上升
→ 日志：批量更新持锁过久
→ 处理：终止异常任务/降级写入
→ 验证：错误率、延迟、锁等待恢复
→ 复盘：拆批、超时、任务限速和告警
```

### 安全视频交付

使用 HTTPS、短期授权 URL、许可证服务、DRM、设备/账户策略、动态水印和风控组合。HLS AES-128 静态 key 即使再包一层加密，客户端最终仍需得到可用 key；不能把“二次加密”当作防盗终点。

## 常见问题与排查

- 告警很多但没人处理：减少不可行动告警，按 SLO 和用户影响重建。
- 日志无法串联：统一 request_id/trace_id，并透传到 Nginx、应用和消息。
- 指标成本暴涨：查高基数标签和抓取频率。
- 密钥泄露：撤销/轮换、查访问日志、缩小权限、重加密受影响数据并复盘传播路径。
