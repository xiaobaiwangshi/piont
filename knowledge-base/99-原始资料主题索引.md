# `raw_doc_` 原始资料主题索引

## 作用

本索引用来回答三个问题：某本旧资料还能提供什么稳定知识、哪些内容必须按版本校正、知识应进入哪个主题章节。它不是阅读顺序，也不把书籍目录重新复制一遍。

`raw_doc_` 是只读档案；抽取文本、图片、OCR 和 CHM 内容全部写入 `tmp/`。最终学习入口始终是 [知识库首页](README.md)。

## 处理方法

1. 用 `pdfinfo` 读取页数与页面大小，用 `pdffonts`、`pdfimages -list` 判断文本型或扫描型。
2. 文本型 PDF 使用 `pdftotext -layout`；扫描型只把目录和目标章节以 300 DPI 写入 `tmp/`。
3. 扫描页用 Tesseract `chi_sim+eng` 形成检索文本；页码、标点、术语、表格、公式和固定数字必须回看原图。
4. ZIP、CHM 用 `7zz` 在 `tmp/` 展开，不在原始目录生成旁文件。
5. 旧资料提供问题模型和稳定原理；版本行为用开放教材、RFC 或官方手册交叉验证。

## 结论分级

- **稳定原理**：直接融合，例如局部性、滑动窗口、B+ 树、WAL、消息确认。
- **版本相关**：写清版本和配置，例如 InnoDB 页大小、Redis 内部编码、RabbitMQ 队列类型。
- **历史做法**：只解释迁移原因，例如分类地址、MySQL Query Cache、RabbitMQ 镜像队列。
- **存疑内容**：未找到一级来源或无法复现实验时，不进入正文。
