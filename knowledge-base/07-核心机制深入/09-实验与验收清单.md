# 实验与验收清单

知识扩展以“能验证”为完成标准。每个实验记录版本、配置、输入、预期、实际结果和原因。

## 四大基础

- 组成原理：对顺序数组与随机链表做 benchmark，比较 cache miss。
- 组成原理：查询 Cache line、OS page 和数据库页，解释三种粒度为何不同。
- 网络：计算 BDP 和可用发送预算；用 `ss -ti` 观察 cwnd/RTT；用限速、时延和丢包环境观察慢启动与吞吐变化。
- 操作系统：写一个非阻塞 epoll 小服务，对比 LT/ET；观察 fd 与上下文切换。
- 操作系统：制造 major fault、已删除文件占盘和 fd 耗尽，使用 `/proc`、日志与系统指标取证。
- 算法：实现 LRU、Top K、BFS/Dijkstra；用反例验证贪心找零边界。

## Web 与运行时

- Nginx：静态、反向代理、FastCGI、SSE 各做最小配置并记录缓冲差异。
- PHP-FPM：逐步增加并发，记录 active/idle/listen queue、RSS、CPU 和 p99。
- Go：制造 goroutine 泄漏，用 pprof 找到；再用 context 修复。
- API：验证幂等、超时、重复请求、非法身份和优雅关闭。

## 数据组件

- MySQL：查询页大小和 Buffer Pool，建不同宽度表，比较 B+ 树扇出/树高估算、索引大小与 `EXPLAIN ANALYZE`。
- Redis：采样 `MEMORY USAGE`，推导百万 key 内存并与实际 RSS 对比。
- Elasticsearch：自定义 analyzer，观察 token；对比 term/match 与深分页/search_after。
- Kafka：制造消费者停止和重复投递，验证 lag、幂等和重放。
- RabbitMQ：在 publisher confirm、业务提交和 consumer ack 前后中断，记录丢失/重复边界、prefetch 和死信重放。

## 架构

- Outbox：数据库提交后杀发布器，重启验证消息最终发出且消费者不重复产生业务结果。
- 限流：实现令牌桶，验证稳定速率与突发容量。
- 故障演练：停止一个应用、缓存或副本，验证健康检查、降级、告警与恢复。
- 容量：用 CPU time、Little's Law 和内存公式预测上限，再用压测解释偏差。

## 安全与可观测性

- SQLi/XSS/CSRF/IDOR 各做隔离测试案例，证明防护在服务端生效。
- 建立 RED dashboard 和一个 99.9% SLO，注入错误验证 burn-rate 告警。
- 用 trace_id 串联 Nginx、应用、消息和数据库日志。
- 演练密钥轮换与撤销，不在生产使用测试密钥。

## 音视频

- 同一素材用不同 CRF/preset 输出，记录 VMAF、大小和编码时间。
- 生成两档关键帧对齐 HLS，验证 ABR 切换。
- 移动 `moov` 前后比较首播行为。
- 验证 AES-HLS key 鉴权，并明确授权客户端仍可获得可解密内容。
