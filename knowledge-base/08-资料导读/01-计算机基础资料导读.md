# 计算机基础资料导读

## 1. 总体路线

先用 [OSSU 课程路线](../../learning-materials/01-计算机基础/ossu-computer-science/) 或 [计算机自学指南](../../learning-materials/01-计算机基础/cs-self-learning/) 选择课程，不要求按仓库顺序全部读完。主线是组成原理 → 操作系统 → 网络 → 数据结构与算法。

## 2. 计算机组成原理

### 基础

掌握二进制、指令、寄存器、流水线、Cache、虚拟地址、总线和 I/O。推荐从 [RISC-V ISA Manual](../../learning-materials/01-计算机基础/riscv-isa-manual/) 中按需核对指令定义，不把规范当入门教材通读。

### 深入与实验

- [NEMU](../../learning-materials/01-计算机基础/nemu/)：从模拟器理解取指、译码、执行、异常和设备。
- [南京大学 PA 讲义](../../learning-materials/01-计算机基础/ics-pa-gitbook/)：按实验把程序、编译器、ISA、操作系统连接起来。

### 应解决的问题

- 为什么局部性、批处理和顺序访问通常更快。
- Cache line、页和磁盘块为什么是不同粒度。
- CPU 使用率高、负载高、内存慢分别意味着什么。

## 3. 操作系统

### 基础教材与代码

- OSTEP 的正文从其官方站点阅读；本地 [OSTEP 配套代码](../../learning-materials/01-计算机基础/ostep-code/) 用于进程、调度、虚拟内存、并发和持久化实验。
- [xv6 教材源码](../../learning-materials/01-计算机基础/xv6-riscv-book/) 配合 [xv6 RISC-V](../../learning-materials/01-计算机基础/xv6-riscv/) 阅读系统调用、页表、锁、调度、文件系统和设备驱动。
- [Linux Kernel 官方源码](https://www.kernel.org/)只作为可选的高阶实现参考，不在本地保存完整源码，也不从 `init/` 开始顺序阅读。

### 推荐实验

1. 跟踪一次系统调用从用户态进入内核再返回。
2. 比较进程、线程和协程的栈、调度者与切换成本。
3. 制造缺页、文件描述符耗尽和锁竞争，并用系统工具确认。

## 4. 计算机网络

### 系统教材

[Computer Networks: A Systems Approach](../../learning-materials/01-计算机基础/computer-networks-systems-approach/) 从链路、互联网、端到端协议延伸到拥塞控制和应用协议。

### TCP 必学机制

- 发送窗口由接收窗口、拥塞窗口和应用数据共同约束。
- 慢启动按确认增长拥塞窗口；进入拥塞避免后增长变缓。
- 超时、重复 ACK、SACK、快速重传、RTO 和 RTT 估算相互关联。
- TCP 以 RFC 为准，Linux 内核只是具体实现；CUBIC、BBR 不能替代 TCP 基础语义。

### 推荐实验

使用抓包和 Linux `ss`/`tc` 观察握手、窗口扩大、重传、延迟和带宽限制。实验结论应同时记录网络条件、内核和拥塞控制算法。

## 5. 数据结构与算法

- [Open Data Structures](../../learning-materials/01-计算机基础/open-data-structures/)：建立数组、链表、树、堆、哈希和图的系统知识。
- [cp-algorithms](../../learning-materials/01-计算机基础/cp-algorithms/)：查阅算法推导和实现边界。
- [The Algorithms/Python](../../learning-materials/01-计算机基础/the-algorithms-python/)：参考实现，不代替复杂度证明和测试。

重点连接实际系统：B+ 树对应数据库索引，堆对应调度与 Top K，哈希对应缓存和分区，跳表对应有序集合，日志结构对应消息系统和存储引擎。

## 6. 验收

- 能解释一次指令、系统调用、TCP 请求和 B+ 树查询的完整路径。
- 能用实验区分 CPU、内存、磁盘和网络瓶颈。
- 能根据数据规模计算复杂度、索引扇出和大致树高，而不是只背结论。
