# AI 与大模型基础、Transformer

## 学习目标与阅读方式

本章是 Agent 开发必修。完成后应能：

- 区分 AI、机器学习、深度学习、NLP、基础模型和 LLM。
- 解释文本如何经过 tokenizer、embedding、Transformer 和输出头生成 token。
- 理解训练、SFT、对齐和推理的关系，而不把它们混成一次“学习”。
- 判断 temperature、top-k/top-p、上下文长度、embedding 和参数量的能力边界。
- 阅读 Attention、显存和 KV Cache 的数量级推导。

向量、Attention 和显存公式见[大模型核心机制](../07-核心机制深入/10-大模型核心机制.md)。本章只整理知识，不训练或运行模型。

## 概念边界

```text
人工智能
└─ 机器学习：从数据中拟合规则
   └─ 深度学习：用多层神经网络学习表示
      └─ 生成模型：学习数据分布并产生新样本
         └─ 大语言模型：在大规模文本/token 上训练的语言模型
```

- NLP 是处理自然语言的任务领域，不等于某种模型。
- 基础模型在通用数据上预训练，可适配多种下游任务。
- LLM 的核心训练目标常是根据已有 token 预测后续 token；“理解”“推理”是行为描述，不意味着内部存有可查询的事实数据库。
- 多模态模型把图像、音频等编码为模型可处理的表示，仍需处理对齐、上下文和评测问题。

## 必要数学直觉

- 向量：一组有方向/位置意义的数，embedding 用向量表示 token 或文本。
- 点积：衡量两个向量方向和幅度的组合关系；Attention 用 query 与 key 的点积产生相关分数。
- 矩阵乘法：批量完成线性变换；神经网络大量计算可归结为矩阵乘法。
- softmax：把一组 logits 转成总和为 1 的概率分布；只表达模型相对偏好，不保证事实正确。
- 对数与交叉熵：对正确 token 概率低的预测给予更大损失。
- 梯度下降：沿减小损失的方向更新参数；反向传播高效计算每个参数对损失的影响。

训练集用于更新参数，验证集用于选模型/超参数，测试集用于最终评估。测试数据泄漏进训练或反复调参会让分数失真。

## Tokenization

模型不直接读取“词”，而读取 token ID：

```text
原始文本 → 规范化 → 子词切分 → token IDs → embedding vectors
```

常见方法：

- BPE：反复合并高频相邻单元。
- WordPiece：按语言模型/似然相关目标选择子词。
- Unigram：从较大候选词表逐步裁剪，选择概率更好的切分。
- SentencePiece：把原始文本作为字符序列处理，可实现 BPE/Unigram，减少语言特定预分词依赖。

同一文本在不同 tokenizer 下 token 数不同。中文、代码、数字、空白和罕见字符的切分会影响上下文占用、成本和模型能力。词表更大不必然更好：embedding 参数增加，稀有 token 学习不足，跨语言效率也会变化。

## Embedding 与相似度

token ID 经 embedding 矩阵查到向量。训练让某些语义/上下文相近的表示在向量空间接近。句向量模型通常单独训练或池化，不能假设生成模型任意隐藏层就是最佳检索向量。

余弦相似度衡量方向接近程度，但：

- 相似不等于事实相同、蕴含或业务可替代。
- 向量维度更高不自动提高检索质量。
- 查询和文档需要与 embedding 模型的训练方式、语言和领域匹配。
- 模型升级后向量空间可能变化，旧新向量不应无验证混用。

## 语言模型与训练目标

自回归语言模型分解序列概率：

```text
P(x1...xn) = Π P(xt | x1...x(t-1))
```

训练时常用 teacher forcing：预测第 t 个 token 时输入真实前缀；推理时前缀包含模型自己刚生成的 token，因此早期错误会影响后续。

交叉熵降低意味着模型给真实下一个 token 更高概率；perplexity 是平均负对数似然的指数形式，适合同一 tokenization/数据条件下比较。低困惑度不直接等于指令遵循、事实正确或安全。

## Transformer 数据流

以 decoder-only 模型为例：

```text
token IDs
→ token embedding + 位置信息
→ N 个 Transformer block
   ├─ Norm → causal self-attention → residual
   └─ Norm → FFN/MLP → residual
→ final norm → vocabulary projection
→ logits → sampling/decoding → next token
```

### Self-Attention

输入表示分别投影为 Q、K、V。Q 与 K 计算当前 token 应关注哪些历史位置，softmax 后对 V 加权。causal mask 阻止生成位置看到未来 token。

Attention 适合建模远距离依赖，但标准实现的 score 矩阵随序列长度平方增长。FlashAttention 等优化减少中间数据搬运和显存访问，不等于上下文长度可以无成本无限增长。

### 其他组件

- Residual：让 block 学习增量并改善深层网络优化。
- LayerNorm/RMSNorm：控制激活尺度、稳定训练；不是普通业务数据标准化。
- FFN/MLP：对每个位置做非线性变换，通常占大量参数和计算。
- 位置编码：向模型提供顺序信息；RoPE 把位置信息作用到 Q/K。
- MHA：多个 query head 各有注意力表示。
- MQA/GQA：共享或分组共享 K/V head，减少 KV Cache 和带宽，可能有质量权衡。
- MoE：每个 token 路由到部分专家，增加总参数而不等比例增加单 token 计算，但引入路由、负载均衡和通信问题。

## 模型架构边界

- Encoder-only：双向编码，适合理解、分类、embedding 等任务。
- Encoder-Decoder：编码输入再自回归解码，适合翻译、摘要等输入输出转换。
- Decoder-only：按前缀自回归生成，训练/推理形式统一，现代通用生成模型常用。

架构选择不是绝对优劣。任务、训练数据、参数/计算预算和推理方式共同决定结果。“Decoder-only 永远最好”或“参数多一倍就更聪明”都是错误简化。

## 模型生命周期

```text
预训练 → 持续预训练（可选）→ SFT/指令微调
→ 偏好/安全对齐 → 量化或服务优化 → 推理与持续评测
```

- 预训练：从大规模数据学习语言、知识和通用模式。
- 持续预训练：用新增或领域无标注数据继续训练，可能改善领域表示，也可能遗忘或污染。
- SFT：用输入—理想输出示例训练指令行为。
- PEFT/LoRA：只训练少量附加/低秩参数，降低显存和存储成本。
- 偏好对齐：用人类/模型偏好数据改善回答风格、安全和任务遵循，RLHF/PPO、DPO 是不同实现路线。
- 推理：参数通常固定，根据输入逐 token 生成；对话不会自动写回模型权重。

## 生成与采样

输出头为每个词表 token 产生 logits：

- greedy：每步选最大概率，稳定但可能重复或局部最优。
- temperature：缩放 logits；低温更集中，高温更随机，0 附近的具体行为依 API。
- top-k：只从概率最高的 k 个 token 采样。
- top-p：从累计概率达到 p 的最小候选集合采样。
- beam search：维护多条高分序列，常用于受约束序列任务，不一定适合开放对话。

随机种子、并行计算、服务实现和模型版本都可能影响可复现性。temperature=0 也不能保证所有平台永久返回相同结果。

## 为什么会幻觉

模型优化的是 token 预测，不是数据库约束。幻觉可能来自：训练知识缺失/冲突、问题歧义、上下文不足或错误、检索失败、长上下文注意力失效、推理错误、工具错误和采样随机性。

RAG、工具、提示和微调都只能解决部分来源。高风险事实需要权威数据、引用、校验或人工审批，不能要求模型“绝对不要幻觉”后假设问题消失。

## 常见误区

1. LLM 是存放事实的数据库：错误，它通过参数建模概率模式。
2. token 等于字符或单词：错误，取决于 tokenizer。
3. embedding 相似就表示事实相同：错误，只表示特定模型空间中的接近。
4. 上下文窗口有 1M token 就能同等利用所有位置：错误，支持长度与有效检索/推理不同。
5. Attention 权重就是可解释因果：错误，它只是内部计算信号之一。
6. temperature=0 永远确定：错误，服务和计算仍可能变化。
7. 参数越多任何任务越好：错误，数据、训练、推理预算和任务匹配同样重要。
8. SFT 会持续学习企业最新事实：错误，更新权重成本高且难追溯，动态事实常更适合 RAG/工具。
9. 对话历史就是长期记忆：错误，历史受上下文和摘要限制。
10. Agent 开发不需要理解模型：错误，不理解 token、采样和上下文就无法可靠排障。

## 自测题与答案

1. **tokenizer 为什么影响成本？** API 常按 token 计费，上下文限制也以 token 计；不同语言/内容切分比例不同。
2. **softmax 概率为何不等于事实置信度？** 它表示给定上下文下 token 的相对偏好，模型可能对错误序列也高度集中。
3. **causal mask 做什么？** 阻止位置关注未来 token，保持自回归训练目标。
4. **Residual 与 Norm 的职责？** Residual 保留/累加信息并利于梯度传播，Norm 控制激活尺度、稳定优化。
5. **MQA/GQA 为什么利于推理？** 减少 K/V head 数，从而降低 KV Cache 与读带宽。
6. **预训练、SFT、推理区别？** 预训练学习通用模式，SFT 学指令行为，推理固定权重生成结果。
7. **为什么 teacher forcing 会产生暴露偏差？** 训练看真实前缀，推理看自己的输出，错误可能累积。
8. **top-k 与 top-p 区别？** top-k 固定候选数，top-p 按累计概率动态决定集合。
9. **长上下文为何不是长期记忆？** 它有容量、成本、注意力和生命周期边界，不提供持久、权限、冲突和删除语义。
10. **Agent 工程师为何仍需模型基础？** 才能解释上下文、采样、结构化输出、检索和性能失败，选择正确补救层。
